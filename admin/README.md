# EverSupport Admin — Frontend Prototype

این پوشه یک نمونه اولیه فرانت‌اند فارسی و راست‌چین برای پنل مدیریت EverSupport است.

## اجرا
1. فایل ZIP را استخراج کنید.
2. `index.html` را در مرورگر باز کنید؛ برای تجربه بهتر می‌توانید از افزونه Live Server در VS Code استفاده کنید.
3. منوهای داشبورد، مدیریت لیدها و نمونه‌کارها را امتحان کنید.

## مهم
- لیدهای موجود، داده‌های نمونه هستند؛ از Google Sheets خوانده نمی‌شوند.
- تغییر وضعیت لیدها فقط تا زمان رفرش صفحه در حافظه باقی می‌ماند.
- نمونه‌کارها فعلاً در localStorage همین مرورگر ذخیره می‌شوند؛ تصاویر با URL نمایش داده می‌شوند، نه آپلود واقعی.
- این نسخه ورود امن ندارد و نباید به‌عنوان پنل واقعی روی اینترنت منتشر شود.
- پیش از استفاده واقعی باید Supabase Auth، دیتابیس با سیاست‌های RLS، Storage و اتصال امن به Google Sheets / Apps Script اضافه شوند.
- هرگز Supabase service_role key یا رمزهای محرمانه را داخل فرانت‌اند قرار ندهید.
